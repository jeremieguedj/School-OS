# Fact-flag decision table

Evaluate each substantive source claim independently.

| Source claim type | Action | Guideline | Update | Durable |
|---|---:|---:|---:|---:|
| Finite unresolved parent request, decision, deadline, form, payment, or attendance commitment | yes | no | optional | optional |
| Standing routine, conditional behavior, recurring school rule | no | yes | no | optional |
| Current news/status with no task/rule | no | no | yes | optional |
| Lasting reference fact | no | optional | optional | yes |
| Greeting, signature, boilerplate, exact duplicate | no | no | no | no |

Rules:

1. A guideline is never an action.
2. An action is not silently converted to update prose.
3. A received date is evidence metadata, not a deadline.
4. When a source is ambiguous, preserve an explicit unresolved/no-fact coverage outcome rather than invent a task or guideline.
5. A source claim may support multiple independent flags only when each use is directly supported.
