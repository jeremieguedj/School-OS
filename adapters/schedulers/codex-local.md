# Codex local scheduler adapter

Status: selected alpha.13 qualification plan; unattended evidence pending.

The currently observed project inventory contains no eligible local Codex
project for a standalone cron task. This adapter therefore does not invent a
cron workaround or claim cron conformance. The selected scheduled test surface
is a Codex thread heartbeat created only after separate user authorization.

The eventual heartbeat prompt will contain only the stable bootstrap reference,
operation name, scheduled entrypoint, and installed-runtime instruction. It
must invoke the same concrete installed daily entrypoint as the qualified manual
path, once that entrypoint exists and is accepted, with a scheduled capability
profile and the exact selected capability list. The first observed scheduled
qualification is read-only. A later TEST send is allowed only after manual
acceptance and all brief/delivery gates pass.

After the scheduled TEST run, inspect the heartbeat state, pause or delete it as
authorized, and read back the inactive state. Record its thread identity,
authorization, model/effort, connector availability, retry/overlap behavior,
and actual run result privately. Do not infer background authorization from the
interactive bridge probe. Do not enable a recurring production schedule from
repository or synthetic evidence.
