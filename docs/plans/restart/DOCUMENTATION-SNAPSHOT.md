# OrgoS Restart Documentation

This is the user-requested recoverable documentation checkpoint immediately
before restart implementation and retirement of legacy active files.

- Git tag: `orgos-restart-documentation` (annotated; do not move it).
- GitHub release display name: **OrgoS Restart Documentation**.
- Snapshot branch: `codex/restart-school-os`.
- Subsequent implementation branch: `codex/restart-implementation`, created from
  this tag in the existing repository directory.
- Earlier baseline: `restart-baseline-2026-09-14`, preserving the original
  pre-cleanup implementation.

The tag fixes the complete tracked tree: product principles, decision ledger,
approved metadata identity and concrete data/index contract, architecture guides,
whole-scope coverage, plans/progress, authored helper/instruction material and
unchanged frozen studies. Git history also preserves the retired implementation.
Private/untracked instance data and credentials are deliberately excluded.

All published architecture questions are now explicitly approved, including
Q1/Q2 concrete records/indexes, Q4 simplified discovery and Q6 completed-email
reuse. Older historical pages preserve their earlier status; the current plan's
approval ledger controls. The snapshot does not claim finished implementation,
functional validation, provider compatibility or successful ingestion.

To inspect the checkpoint on GitHub, open the release/tag and browse its source.
To work from it locally without rewriting history, first preserve any current
uncommitted work, then create a separate branch from `orgos-restart-documentation`.
Do not reset or force-push the implementation branch merely to inspect the past.

Implementation retains approved principles and evidence but removes the old
runtime, old canonical schemas/installers and their competing instructions from
active operation. No legacy architecture is adopted by preserving its history.
The release is marked as a documentation prerelease and is not a runnable package.
